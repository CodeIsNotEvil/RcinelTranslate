# 2026-11-02

- Preparing the 0.1.0 release. CHANGELOG.md's section said "Unreleased", which the tag check in
  `ci.yml` rejects (it wants `## 0.1.0 - <date>`), so it's dated 2026-11-02. If the tag goes out on
  a later day, change the date first.
- PyPI publishes through trusted publishing (`pypa/gh-action-pypi-publish`, OIDC) like NuGet, so
  `PYPI_API_TOKEN` is gone. PyPI takes a pending publisher for a project that doesn't exist yet, so
  the first upload needs no token either.
- npm and crates.io keep their tokens for now: both only let you add a trusted publisher once the
  package exists. npm can move after 0.1.0 is out; the job needs npm >= 11.5 for OIDC then.
- Maven Central has no trusted publishing; it stays a Central Portal user token plus a GPG key
  (key ID 5A2D9BAEFE52708A, on keyserver.ubuntu.com and keys.openpgp.org). The owner keeps the key
  backup outside the repository.
